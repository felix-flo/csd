# 101. 테스트 모드 (탭 로그인) — 리프레시 토큰 없이 탭마다 로그인

> 작성일: 2026-10-29
> 상태: **구현 완료 (2026-10-29)**. API e2e 23건 통과, 브라우저로 탭 A 관리자 · 탭 B 프레젠테이션 동시 로그인 확인. **로컬·Pi `.env` 의 토큰 수명은 직접 고쳐야 함** (§4)
> 관련: [90.개발환경초안.md](90.개발환경초안.md) (토큰·환경변수), [96.게임준비_리셋.md](96.게임준비_리셋.md)

## 1. 배경

- 리프레시 토큰은 httpOnly 쿠키(`csd_refresh`)라 **같은 브라우저 세션의 모든 탭이 공유**한다. Chrome·Firefox 는 시크릿 창도 전부 한 세션이라, 관리자가 한 기기에서 여러 계정(관리자·리더·프레젠테이션)으로 테스트하면 새 탭이 앞 계정으로 자동 로그인된다 (Safari 는 사설 탭마다 세션이 달라 그렇지 않다).
- 토큰 수명을 줄여도 탭이 나뉘지 않고, "새 탭에서 자동 로그인만 막기"는 쿠키 하나를 두 계정이 덮어쓰므로 반쪽이다.
- 코드 없이 쓰는 우회: 탭마다 다른 호스트(`localhost` / `127.0.0.1` / `a.localhost` …)로 열면 쿠키가 분리된다. 이 문서의 기능은 그보다 편한 **운영 설정**이다.

## 2. 결정 (2026-10-29)

| # | 항목 | 결정 |
|---|---|---|
| 1 | 모드 전환 | 관리자 **게임 설정 카드 체크박스** "테스트 모드 (탭 로그인)". DB `game.tab_login` 에 저장. 시작 전·진행 중 언제든 바꿀 수 있음 (게임 규칙이 아니라 설정 저장과 별도 API) |
| 2 | 켜져 있을 때 | 로그인 응답에 **리프레시 쿠키를 심지 않음**. 액세스 토큰은 클라이언트가 **`sessionStorage`**(탭 단위, 새로고침 유지)에 보관. `/api/auth/refresh` 는 항상 401 + 쿠키 삭제 (앞서 생긴 쿠키 세션도 새 탭에서 되살아나지 않게). 만료·401 이면 재발급 없이 로그아웃 |
| 3 | 꺼져 있을 때 | 현행: httpOnly 쿠키 + 재발급. 단 액세스 토큰은 메모리만 |
| 4 | 액세스 토큰 수명 | ~~두 모드 모두 1시간~~ → 일반 모드 1시간 (`ACCESS_TOKEN_TTL` 기본 `1h`), **테스트 모드 3시간** (`TAB_ACCESS_TOKEN_TTL` 기본 `3h`. 재발급이 없으므로. 2026-10-30 변경) |
| 5 | 리프레시 토큰 수명 | **12시간** (`REFRESH_TOKEN_TTL_HOURS` 기본 `12`. 기존 `REFRESH_TOKEN_TTL_DAYS` 가 있으면 ×24 로 호환) |
| 6 | 끄는 걸 잊지 않게 | 관리자 화면 상단 **"🧪 테스트 모드" 배지** + 게임 시작 확인 팝업에 경고 한 줄. 끄는 건 수동. 리셋 "설정값 초기화" 를 체크하면 함께 꺼짐 |
| 7 | 로그인 화면 안내 | `/api/health` 에 `tabLogin` 을 실어 로그인 화면에 "테스트 모드: 이 탭에서만 로그인됩니다" 표시 |
| - | 보안 | 탭 모드에서는 액세스 토큰이 JS 에서 읽히는 저장소에 있다. **테스트 전용**. 탈락·리셋 차단은 서버가 요청마다 계정 상태를 확인하므로 토큰 수명과 무관하게 즉시 |

## 3. 변경 계획

**데이터**
- `server/migrations/0014_tab_login.sql`: `ALTER TABLE game ADD COLUMN tab_login INTEGER NOT NULL DEFAULT 0`

**서버**
- `config.ts`: `accessTokenTtl` 기본 `'1h'`. `refreshTokenTtlMs` = `REFRESH_TOKEN_TTL_HOURS`(기본 12)×3600000, `REFRESH_TOKEN_TTL_DAYS` 가 설정돼 있으면 그 값×24h 우선 (기존 .env 호환). `auth/tokens.ts`·`routes/auth.ts` 의 `refreshTokenTtlDays * 86_400_000` 을 `refreshTokenTtlMs` 로
- `db/game.ts`: `GameRow.tab_login`, `getSettings().tabLogin`, `setTabLogin(on)`(상태 무관), 리셋 설정 초기화 때 0. `GameState` 에는 넣지 않음 (참가자에게 불필요)
- `routes/game.ts`: `PUT /api/admin/game/tab-login { on }` → adminView
- `routes/auth.ts`
  - `/login`: `tab_login` 이면 쿠키를 심지 않고 기존 쿠키 삭제, 응답에 `tabLogin: true`
  - `/refresh`: `tab_login` 이면 쿠키 삭제 + 401 `tab_login`
  - `/logout`: 그대로 (쿠키 없으면 204)
- `index.ts` `/api/health`: `tabLogin` 추가
- `shared/types.ts` `LoginResponse.tabLogin?: boolean`, `shared/game.ts` `GameSettings.tabLogin: boolean`

**클라이언트**
- `stores/auth.ts`
  - `login()`: `res.tabLogin` 이면 `sessionStorage['csd:access']` 에 토큰 저장, 아니면 삭제
  - `bootstrap()`: ① `sessionStorage` 토큰이 있으면 그걸로 `/api/me` (401 이면 지우고 ②) ② 없으면 지금처럼 refresh
  - `refresh()`: 탭 모드 세션(sessionStorage 토큰 있음)에서는 호출하지 않고 false → 401 시 바로 로그아웃
  - `clear()`: `sessionStorage` 토큰 삭제
- `lib/api.ts`: 그대로 (`auth.refresh()` 가 false 면 기존 흐름대로 `clear`)
- `GameSetupCard.vue`: 체크박스 "🧪 테스트 모드 (탭 로그인) — 리프레시 토큰을 쓰지 않아 탭마다 따로 로그인합니다" (설정 저장과 별도로 바로 저장, 시작 후에도 보이게 게임 진행 카드에도 같은 토글)
- `AdminView.vue` TopBar 옆 배지 "🧪 테스트 모드", `GameControlCard.vue` 시작 팝업 경고: "테스트 모드(탭 로그인)가 켜져 있습니다. 실제 진행이면 게임 설정에서 끄세요"
- `LoginView.vue`: `/api/health` 의 `tabLogin` 이면 안내 한 줄

**문서·환경**
- `.env.example`: `ACCESS_TOKEN_TTL=1h`, `REFRESH_TOKEN_TTL_HOURS=12` (DAYS 줄 삭제)
- [90.개발환경초안.md](90.개발환경초안.md) 환경변수 표 갱신
- **로컬·Pi `.env` 는 직접 고쳐야 한다** (`ACCESS_TOKEN_TTL=15m`, `REFRESH_TOKEN_TTL_DAYS=30` 이 남아 있으면 그 값이 이긴다)

**검증**
- API e2e: 기본 꺼짐 → 로그인 시 쿠키 있음·refresh 200; 켬 → 로그인 응답 `tabLogin`·Set-Cookie 없음·기존 쿠키 삭제, refresh 401, 액세스 토큰으로 API 정상, 관리자 탈락 처리 시 즉시 401; 끔 → 다시 쿠키; 리셋(설정 초기화) 시 꺼짐; `/api/health.tabLogin`
- 토큰 수명: 발급된 JWT `exp` 가 1시간, `refresh_tokens.expires_at` 이 12시간 뒤
- 브라우저: 켠 뒤 탭 A 관리자·탭 B 리더 동시 로그인 유지, 새 탭은 로그인 화면, 새로고침은 유지, 로그아웃 후 새로고침 로그인 화면, 배지·시작 팝업 경고·로그인 안내
- `npm run typecheck`, 기존 e2e 5개 회귀

### .env 를 고치세요

`.env` 값이 코드 기본값보다 우선합니다. 로컬과 Pi 의 `.env` 에서 아래처럼 바꾸지 않으면 15분 / 30일이 그대로 적용됩니다.

```
ACCESS_TOKEN_TTL=1h
REFRESH_TOKEN_TTL_HOURS=12      # REFRESH_TOKEN_TTL_DAYS 줄은 지울 것 (있으면 그 값이 우선)
```
