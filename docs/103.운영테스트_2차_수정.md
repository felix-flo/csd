|---|---|---|

| 8 | 1명 팀 라이프 | `isLifeExempt(활성, 라이프)` = 1명 **이고** 라이프 0 일 때만 면제. 1명이라도 라이프가 있으면 제출해야 하고 **라이프 1개 소모·생존**(살릴 인원 1 고정, 자진 탈락 불가 `bad_count`). 라이프 0·1명은 탈락 없이 자동 생존 |

| 11 | 원조 1회 | **게임 전체 기준 라운드당 1회** (전에는 주는 팀 기준). 처리 뒤 입력 폼 비활성 "이번 라운드 원조 완료", 다음 라운드 다시. 안내 문구 "리더 4명 중 3명 이상 찬성해야 통과" |
| 12 | 협의 안건에 전쟁 허용/제재 | 리더 협의 단계에 관리자가 **다음 라운드 전쟁 허용 / 제재** 입력 (`POST /admin/war/allow`, `war_rules(day, allowed)`, 전체 공지 `war.allowed`). 입력 없으면 허용, 1라운드 허용. 제재된 라운드: 리더 전쟁 패널 "이번 라운드 금지" + 선포 버튼 없음, 서버 `war_banned`. 라운드 시작 공지에 "⚔️ 이번 라운드는 전쟁 금지". **프레젠테이션 협의 단계 카드** "🗣️ 리더 협의 안건": 🤝 원조 (라운드당 1건·4명 중 3명) · ⚔️ 다음 라운드 전쟁 허용/제재 (결과 표시) · (마지막 라운드) 📜 라이프 투표권 (결과 표시) |
| 13 | 최종 투표 때 테러리스트 문구 | **실제로 노출됐음**: 진행 표시줄(`GamePhaseBar`)의 최종장 4단계 칩에 "테러리스트 공개" 가 투표 단계부터 보였다. 테러리스트 공개 단계가 되기 전까지 그 칩을 숨기도록 수정 (관리자 FinalControl 은 그대로) |
| 14 | 단계 타이머 (추가 요청) | **거래 15분 · 리더 협의 5분** 카운트다운을 프레젠테이션에 크게 표시 (`GameState.timer`: 단계 시작 시각 `game.phase_started_at` + 길이, 서버 시각으로 보정). 강제 없음. 0 이 되면 서버가 전체에 **"⏱️ 거래 시간이 종료되었습니다." / "⏱️ 리더간 협의가 종료되었습니다."** 알림 1회 (`phase.timeout`, 소리 있음. `game.phase_timer_fired` 로 1회 보장, 서버 재시작 뒤에도 남은 시간에 맞춰 보냄). 길이는 `shared/game.ts PHASE_TIMER_SECONDS`. 0022 마이그레이션 |

## 데이터

`server/migrations/0021_offline_ops.sql`
- `trades` 재생성: status `proposed | completed | rejected | cancelled`, `credit_payer`·`from_offer`·`to_offer` NOT NULL. 옛 진행 중 거래는 cancelled
- `wars` 재생성: status 에서 `pending`·`rejected` 제거 (`reject_reason` 삭제). 옛 pending 은 cancelled, rejected 행은 버림. `idx_wars_one_per_day ON wars(day)` 단순 유니크
- `war_rules (day PK, allowed)` 추가

## 검증

- API e2e (`scratchpad e2e/ops2.py`): 매장량 없는 설정·생산, 관리자 거래 제안→양쪽 수락→체결(크레딧·교환), 거부→취소, 보유 부족 거부, 전쟁 즉시 선포(비용·거래 취소)·중복 선포 거부·결과 후 협의 자동 전환, 원조 라운드 1회, 전쟁 제재 → 다음 라운드 선포 거부, 1명 팀 라이프(0 면제·1 이상 제출·자진 탈락 불가), 발행 즉시 반영·라운드 1회
- 브라우저: 관리자 거래 입력 폼·팀 색 강조, 리더 거래 강조 박스, 프레젠테이션 협의 안건 카드, 토스트 sticky, 알림 접기
