# 03. 전체 룰 (운영진용)

> 운영진(블랙)만 보는 전체 규칙. 플레이어에게는 04 공지 룰과 05 팀별 룰만 공개한다.

## 1. 기본

| 항목 | 내용 |
|---|---|
| 팀 | 화이트 · 골드 · 블루 · 레드 + 블랙(운영진, 게임 미참여·보상 없음) |
| 진행 | 6라운드 + 최종장 |
| 승패 | 팀 단위. 최종 투표로 채택된 화폐(보석 또는 골드) 보유 비율로 팀 보상 결정 |
| 재화 관리 | 웹앱 (개인 휴대폰). 재화는 팀 공동 소유 |
| 공간 | 제한 없음. 다른 팀 재화 보유량은 볼 수 없음 |

## 2. 팀 구성

| 플레이어 | 화이트 | 골드 | 블루 | 레드 |
|---|---|---|---|---|
| 22 | 7 | 7 | 4 | 4 |
| 23 | 8 | 8 | 3 | 4 |
| **24 (기준)** | **8** | **8** | **4** | **4** |
| 25 | 8 | 8 | 5 | 4 |
| 26 | 8 | 8 | 5 | 5 |

- 팀 선택: A·B·C·D 중 선착순. 앱에는 정원/현재 인원만 표시 (예: `A (4/8)`). 팀 정체는 선택 후 공개.

## 3. 재화와 초기값 (24명 기준)

| 팀 | 보석 | 골드 | 라이프 | 크레딧 |
|---|---|---|---|---|
| 화이트 | 200 | 0 | 8 | 3 |
| 골드 | 0 | 200 | 10 | 3 |
| 블루 | 0 | 0 | 16 | 3 |
| 레드 | 0 | 0 | 5 | 15 |
| 합계 (시작 시 공개) | 200 | 200 | 39 | 24 |

- 인원이 바뀌면 초기 라이프: 화이트 1인당 1 · 골드 1인당 1 + 2 · 블루 1인당 4 · 레드 1인당 1.25 (내림)

| 재화 | 쓰임 |
|---|---|
| 라이프 | 라운드 끝 제출. 최종장 추가 투표권 (안건 통과 시) |
| 크레딧 | 생산게임 참가·추가판, 거래 수수료, 전쟁 선포 |
| 보석 | 보석 채택 시 보상 |
| 골드 | 골드 채택 시 보상 |

## 4. 생산게임

- 참가비 크레딧 1 (팀당 라운드당). 크레딧이 없으면 참가 불가 → 생산 0.
- 시작 전에 **라이프 또는 크레딧 중 하나만** 선택.
- 운영진과 미니게임 10판 (가위바위보, 묵찌빠, 10초 타이머 맞추기 등). 추가판은 크레딧 1개당 1판, 최대 3판 (미니게임마다 다르게 운영 가능).
- 출전자는 팀이 정함.

| 팀 | 라이프 선택 시 | 크레딧 선택 시 |
|---|---|---|
| 화이트 | 기본 2 + 2승당 1 | 2승당 1 |
| 골드 | 기본 2 + 2승당 1 | 2승당 1 |
| 블루 | 1승당 2 | 3승당 1 |
| 레드 | 2승당 1 | 1승당 3 |

## 5. 발행

| | 화이트 (보석) | 골드 |
|---|---|---|
| 횟수 | 라운드당 1회, 원하는 시점에 | 라운드당 1회, 원하는 시점에 |
| 한도 | 250 | 200 |
| 안 쓴 한도 | 소멸 | 다음 라운드로 누적 |
| 공개 | 비공개 (화이트·운영진만) | 현재 발행량을 현황판에 상시 공개 |
| 라운드 6 | 리더 협의가 끝난 뒤에만. 발행량은 최종장 결과 때 공개 | 리더 협의가 끝난 뒤에만. **현황판에 반영하지 않고** 최종장 결과 때 공개 |

- 다른 팀은 한도의 존재·수치·방식을 모름. 보석 발행량은 어떤 질문에도 답하지 않음.
- 최종장에는 발행 없음.

## 6. 거래

- 리더가 앱에 거래를 올리고 상대 팀 리더가 수락하면 성립.
- 수수료 크레딧 1 / 건. 누가 낼지는 두 팀이 정함.
- 어떤 재화든 어떤 비율로든 교환 가능.
- 제재받은 팀은 해당 라운드에 거래 불가.
- 최종장에는 거래 없음.

## 7. 전쟁

| 항목 | 내용 |
|---|---|
| 선포 | 거래 시간에 리더가 크레딧을 내고 선포. 취소 불가 |
| 비용 | 크레딧 3에서 시작. 전쟁이 잦거나 한 팀이 계속 털리면 운영진이 4~5로 인상하고 공지 |
| 횟수 | 게임 전체에서 라운드당 1번. 총 횟수 제한 없음 |
| 거부 | 선포당한 팀이 거부하면 패배 |
| 동맹 | 가능. 전리품·비용 분배는 동맹끼리 |
| 진행 | 진행 정지 → 스위치 마리오 대결 |
| 결과 | 이긴 팀이 진 팀 모든 재화(보석·골드·라이프·크레딧)의 절반 획득 (내림) |
| 공개 | 다른 팀에는 승패만. 오간 재화는 두 팀만 확인 |
| 중 | 전쟁이 끝날 때까지 모든 거래 정지 |

## 8. 리더 협의

- 매 라운드 끝. 리더 4명 중 3명 찬성으로 통과.
- 리더가 올릴 수 있는 안건: **원조 또는 제재 중 하나** (라운드당 1개, 안 해도 됨)
  - 원조: 주는 팀 리더가 먼저 "원조하겠다"고 선언해야 투표 시작. 통과 시 수수료 없이 재화 1회 양도
  - 제재: 통과 시 다음 라운드에 한 팀 거래 불가
- 그 밖의 안건은 운영진이 제시: 전쟁 금지 / 전쟁 재개 등
- **라운드 6 필수 안건:** "남은 라이프를 최종 투표권으로 인정할까요?" (라이프 1개 = 투표권 1장, 1인 1장)

## 9. 라이프 제출과 탈락

- 리더가 앱에 **쓸 라이프 개수**와 **자진 탈락 여부**를 입력. 쓴 개수만큼만 생존.
- 라이프가 충분해도 적게 쓸 수 있음.
- 리더가 자진 탈락하지 않으면 리더는 자동 생존, 나머지 자리는 리더 외 팀원 중 앱이 무작위로 정함.
- 리더가 자진 탈락하면 모든 자리를 리더 외 팀원 중 무작위로 정함.
- 리더 외 팀원은 자진 탈락 불가.
- 팀 라이프가 0개면 1명만 생존 (리더, 또는 리더 자진 탈락 시 무작위 1명). 이 1명은 제출 면제.
- 리더가 탈락하면 남은 팀원이 다음 라운드 리더를 뽑음.
- 탈락자는 보상 자격 상실. 팀 재화는 팀에 남음.

## 10. 이주

- 라운드 4부터 라운드 6까지. 라운드 중 언제든 (생산게임 전 포함).
- 개인이 앱으로 신청 → 받는 팀 리더에게만 전달 → 수락 시 전체 공지, 즉시 소속 변경.
- 빈손으로 이동. 이후 라이프는 새 팀이 냄.
- 리더는 신청 불가. 횟수 제한 없음.
- 최종장에는 이주 없음.

## 11. 최종장

| 순서 | 내용 |
|---|---|
| ① 최종 투표 | 각자 앱에서 비밀·동시 투표 (개인 단위). 기본 1인 1표 + (라운드 6 안건 통과 시) 남은 라이프 1개당 1표, 1인 1장까지. 화폐로 표를 살 수 없음 |
| ② 결과 | 채택 화폐 발표. 동점이면 화이트 리더 vs 골드 리더 가위바위보. 라운드 6 발행량 공개 |
| ③ 정산 | 팀 보상 = 전체 × (팀 보유 채택 화폐 ÷ 모든 팀 보유 채택 화폐) |
| ④ 스파이 공개 | 정체와 스파이 보상 공개 |

- 보석 채택 시 골드 팀, 골드 채택 시 화이트 팀은 보상 0 (상대 화폐 보유량 무효, 분모에서도 제외).
- 채택되지 않은 화폐·라이프·크레딧은 0.
- 최종장에는 거래·발행·원조·이주 없음.

## 12. 스파이

| 항목 | 내용 |
|---|---|
| 선정 | 시작 시 앱으로 제안 → 수락자 중 무작위 1명 |
| 행동 | 소속 팀원으로 행동. 팀은 스파이 몫 라이프도 냄 |
| 보상 | 탈락자 1명당 5천 원 적립, 최대 5만 원 |
| 탈락 시 | 적립금 전부 소멸 |
| 소속 팀 보상 | 일부 받음 (보상 확정 후 재논의) |

## 13. 운영진 체크리스트

- 보석 발행량, 라운드 6 골드 발행량은 최종장 결과 전까지 절대 공개하지 않음.
- 현황판: 골드 발행량(라운드 1~5), 전쟁 비용, 이주, 탈락자.
- 전쟁 결과는 승패만 공지.
- 스파이 적립금 기록, 스파이 탈락 시 0으로.
