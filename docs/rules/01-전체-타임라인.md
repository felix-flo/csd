## 한 라운드 순서 (라운드 1~5)

| 순서 | 플레이어 | 운영진 |
|---|---|---|
| ① 리더 선출 | 팀별 합의로 리더 1명 | 앱에 리더 등록 확인 |
| ② 생산게임 | 라이프/크레딧 중 선택 → 미니게임 10판 (+추가판) | 참가비 차감, 게임 진행, 승수 입력 |
| ③ 거래 | 거래 제안·수락, 발행, 이주 신청 (라운드 4부터) | 거래·발행 처리, 현황판 갱신 |
| (전쟁) | 리더가 선포 | 진행 정지 → 마리오 → 전리품 처리 → 승패만 공지 |
| ④ 리더 협의 | 리더 4명 투표 | 운영진 안건 제시, 원조·제재 처리 |
| ⑤ 라이프 제출 | 리더가 사용 개수·자진 탈락 입력 | 앱 무작위 결과 확인 → 탈락자 공지 |
