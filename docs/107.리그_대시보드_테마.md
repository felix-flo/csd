# 107. 리그 대시보드 테마 (CCFE League 톤)

2026-11-01, 브랜치 `design3`. 관리자·프레젠테이션·참가자 세 화면을 "축구 매니지먼트 게임식 다크 대시보드" 톤으로 바꿨다.
레퍼런스는 Superdesign 라이브러리의 CCFE League Dashboard (https://superdesign.dev/library/ccfe-league-dashboard-ultra-detail-fm-edition).
페이지 본문이 JS 라 색·구성은 미리보기 이미지에서 직접 읽었다 (주요 색 `#050a14` `#070d18` `#111d35` `#1a2a4a` `#d4af37`).
배치(docs/105)·가시성 기준(docs/104)은 그대로 두고, 아이콘은 `design2` 브랜치(docs/106)에서 만든 `Icon.vue` 를 가져와 색·폰트·선·머리띠만 바꿨다.

## 3. 컴포넌트

- **카드**: 패널 바탕 + 1px 선, 첫 h2 는 머리띠. `.bracket` 은 왼쪽 3px 금색 띠 (프레젠테이션 타이머·안건).
- **버튼**: 주요 = 금색 채움 + 어두운 글자, 대문자 700. 보조 = 투명 + 1px 선, 호버 시 금색 선·글자. 위험 = 빨강.
- **입력**: 우물 바탕 + 1px 선, 포커스 금색 글로우.
- **뱃지/칩**: 머리띠 바탕 + 1px 선, 모노 대문자. `on` 금색 채움, `off` 빨강, `warn` 주황.
- **단계 바**: 왼쪽 3px 금색, 단계 목록은 **탭** (현재만 금색 글자 + 2px 금색 밑줄, 지난 단계는 흐리게). 최종장 단계(FinalControl)도 같은 탭.
- **상단바**: 아래 1px 선. 화면 맨 위에는 3px 금색 줄 (`body::before`).
- **재화 칩**: 우물 바탕, 숫자·아이콘 색만 재화별 (보석 흰색 · 골드 `#e3bd4a` · 라이프 `#4da3ff` · 크레딧 `#ff6b6b`).
- **프레젠테이션**: 타이머 숫자 Oswald 4rem 금색 글로우(경고·종료는 빨강), 협의 결과 초록, 팀 카드는 우물 바탕 + 팀 색 띠 5px + Oswald/Do Hyeon 팀 이름, 골드 누적 숫자 금색, 대기 화면 팀 글자(A/B/C/D) 금색 글로우.
- **토스트·모달**: 패널 바탕 + 1px 선, 토스트는 왼쪽 3px 금색, 모달은 위 3px 금색.
- **최종 투표·이주 선택 타일**: 선택 시 금색 채움 + 어두운 글자 (흰 글자는 금색 위에서 안 보임).
- **QR**: 스캔을 위해 흰 박스 유지. **팀 색 강조 `teamInk()`**: 아주 어두운 색만 밝은 회색으로.

## 4. 아이콘

`client/src/components/Icon.vue` 인라인 SVG 24종 (재화 4종, 타이머, 협의, 원조, 전쟁, 안건, 투표, 이주, 잠금, 알림음 2종, 무음, 테러리스트, 태양/달, 테스트, 주의, 새 버전, 메가폰, 영상, 트로피). 24×24 뷰박스, 2px 선, `currentColor`.
클래스는 `icon icon-<name>` (부모 scoped 스타일의 `.timer` `.council` 과 겹치지 않게 접두어). 재화 아이콘은 `--res-*-fg` 색.
이모지는 UI 템플릿·서버 알림 메시지·공용 라벨(`PHASE_TIMEOUT_MESSAGES`, `FATE_LABELS`)에서 모두 뺐고(`lib/resources.ts` 의 `emoji` 필드 삭제), 룰북 마크다운만 콘텐츠라 그대로 둔다.

## 6. 운영 메모

- 다크 화면이라 강당 조명이 밝으면 대비가 떨어질 수 있다. 리허설 때 뒷자리에서 타이머·팀 이름을 확인한다.
- 밝은 Geist 테마는 `main`, 전광판(ApexDrill) 다크는 `design2`, 이 리그 대시보드 테마는 `design3`.
