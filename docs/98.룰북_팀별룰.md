# 98. 룰북 — 전체 룰 + 팀별 룰

> 작성일: 2026-10-23
> 상태: **구현 완료**. API e2e 20건(룰북) + 기존 e2e 전체 통과, 브라우저로 팀원·프레젠테이션·관리자(편집 탭·팀원 화면 미리보기) 확인.
> 관련: [96.게임준비_리셋.md](96.게임준비_리셋.md) (시작 전 팀 이름 비공개, 리셋 범위)

## 1. 요구사항 요약

1. 룰은 **전체 룰**과 **팀별 룰**로 나뉜다.
2. 관리자는 전체 룰과 각 팀 룰을 수정한다.
3. 팀원은 전체 룰과 자기 팀 룰을 합쳐서 본다.
4. 프레젠테이션 화면에는 전체 룰만 보인다.
5. 모든 룰은 지금처럼 마크다운으로 편집·보기.

## 2. 결정 사항

| # | 항목 | 결정 |
|---|---|---|
| 1 | 다른 팀 룰 | **자기 팀 룰만**. 서버도 거부 (일반 문서 API 로도 팀 룰은 404) |
| 2 | 게임 시작 전 | **전체 룰만**. 팀 룰은 시작 후 공개 (시작 전에는 팀 이름을 A, B … 로 숨기므로). 시작 전 팀 룰 갱신 알림도 진행자에게만 |
| 3 | 팀원 화면 | 한 페이지: 전체 룰 → 마크다운 가로줄 `---` → `# ○○ 팀 룰` + 팀 룰. 팀 룰이 비어 있으면 전체 룰만 |
| 4 | 팀 추가·삭제·리셋 | 팀 추가 시 빈 팀 룰 자동 생성, 팀 삭제 시 함께 삭제(FK CASCADE), 게임 리셋 때는 유지 |
| 5 | 갱신 알림 | 전체 룰은 전체(scope=all), 팀 룰은 그 팀 + 진행자(scope=group). 다른 팀·프레젠테이션은 팀 룰 수정 사실도 모른다 |
| 6 | 관리자 편집 | 룰 편집 카드에 "전체 룰 / A · 화이트 팀 / B · …" 탭. 탭마다 편집·미리보기·직전 버전 되돌리기. 룰 보기 화면에 "○○ 팀원 화면" 미리보기 선택 |
| 7 | 팀 룰 제목 | 자동 "○○ 팀 룰" (팀 이름이 "팀" 으로 끝나면 "화이트 팀 룰", 아니면 "그린 팀 룰"). 팀 이름을 바꾸면 따라간다 |
| 8 | 리더 전용 룰 | 없음 |

## 3. 데이터 — `server/migrations/0009_team_rules.sql`

| 변경 | 내용 |
|---|---|
| `documents.group_id` | 팀 룰이면 팀 id (`REFERENCES groups ON DELETE CASCADE`), 전체 룰은 NULL |
| slug | 전체 룰 `rules` (기존 문서 그대로), 팀 룰 `team-<groupId>` |
| `idx_documents_group` | 팀당 팀 룰 1개 (partial unique) |
| 기존 팀 | 마이그레이션 때 빈 팀 룰 생성. 이후 추가된 팀은 조회 때 `ensureTeamRules()` 가 만든다 |

## 4. API

| 메서드 | 경로 | 역할 | 설명 |
|---|---|---|---|
| GET | `/api/rules` | 전체 | `{ global, team, teams? }` — 참가자: team = 자기 팀 룰(시작 후, 시작 전 null) / 프레젠테이션: team null / 관리자: teams = 모든 팀 룰 |
| PUT | `/api/admin/rules/team/:teamId` | admin | `{ markdown }` 팀 룰 저장 (직전 버전 보관) |
| POST | `/api/admin/rules/team/:teamId/restore` | admin | 팀 룰 직전 버전으로 |
| GET · PUT · POST | `/api/documents/:slug`, `/api/admin/documents/:slug(/restore)` | | 전체 룰(기존). 팀 룰 slug 는 404 |

- `DocumentInfo.teamId` 추가.
- `document.updated` 이벤트 payload 에 `teamId`.

## 5. 화면

| 화면 | 변경 |
|---|---|
| `/rules` 참가자 | 전체 룰 + 가로줄 + 우리 팀 룰. 팀 이동·게임 시작·리셋 때 다시 받는다 |
| `/rules` 프레젠테이션 | 전체 룰만 |
| `/rules` 관리자 | 상단 선택: "전체 룰만 (프레젠테이션)" / "A · 화이트 팀 팀원 화면" … |
| `/admin` 룰 편집 | 전체·팀별 탭(비어 있는 팀 룰은 "(비어 있음)"), 팀 룰은 제목 입력 없이 자동 제목. 저장하지 않은 변경이 있으면 탭 전환 전에 확인 |
| 갱신 배너 | 팀 룰 갱신은 그 팀에만 "화이트 팀 룰 이(가) 갱신되었습니다" |
