# 107. 참가자 게임 화면 (모바일)

2026-11-01. 참가자 게임 화면(`GroupView`)을 휴대폰 한 화면 기준으로 다시 짰다. 관리자·프레젠테이션 화면과 게임 시작 전 화면(이름 입력·팀 선택)은 그대로다.

## 1. 화면 구성

위에서 아래로 헤더 → 진행 → (최종 결과) → 재화 → 팀원 → 하단 버튼. 영역 제목 줄(`.ttl`)은 팀 색 테두리로 감싸 영역 윗선에 겹친다. 바탕은 팀 색이 위에서 아래로 내려오는 그라데이션이다.

| 영역 | 컴포넌트 | 내용 |
|---|---|---|
| 헤더 | `PlayHeader` | 이름(기울임 + 그라데이션, 길면 말줄임), 연결 상태 아이콘, 역할, 룰북, 설정, 알림함 |
| 진행 | `PlayProgress` | 라운드, 남은 시간(7세그먼트 시계), 단계 바, 지금 할 일 안내 |
| 재화 | `PlayResources` | 2줄 2칸(위 보석·골드, 아래 라이프·크레딧), 그 아래 발행팀의 발행 버튼 |
| 팀원 | `PlayMembers` | 기본으로 펼침. 리더 줄 오른쪽에서 접고 펼친다 |
| 하단 버튼 | `PlayDock` | 지금 단계에서 누를 수 있는 일만. 없으면 영역이 사라진다. 스크롤해도 아래에 붙어 있다 |

- 단계 바는 한 사각형을 화살표로 나눈다. 칸 색이 종료·활성·대기를 뜻한다. 글자는 화살표를 뺀 사각형의 가운데에 둔다.
- 단계 이름은 리더 · 생산 · 거래 · 협의 · 라이프로 줄여 쓴다. 최종장은 최종 투표 · 결과 발표 · 정산이고, 네 번째 칸이 열리면 투표 · 결과 · 정산 · 테러리스트로 줄인다.
- 팀 색은 `lib/teamTheme.ts` 가 CSS 변수로 준다 (`--team`, `--accent`, `--accent-fg`, `--team-line` 등). 확인 팝업은 `body` 로 빠져나가므로 버튼 색 두 개만 `body` 에도 얹는다.

## 2. 하단 버튼과 시트

| 버튼 | 나오는 때 | 누가 |
|---|---|---|
| 거래 확인 / 거래 현황 | 거래 단계에 우리 팀 거래가 올라와 있을 때 | 리더 |
| 전쟁 선포 | 거래 단계, 전쟁 중이 아닐 때. 못 하면 이유를 함께 보여 주고 비활성 | 리더 |
| 라이프 제출 | 라이프 제출 단계, 아직 안 냈고 면제가 아닐 때 | 리더 |
| 최종 투표 | 투표 단계, 아직 안 했을 때 | 리더, 라이프 투표권이 통과했으면 팀원도 |
| 이주 / 이주 대기 / 이주 N건 | 이주 시작 라운드부터 라이프 제출 전까지 | 팀원은 신청, 리더는 받은 신청 처리 |

버튼을 누르면 아래에서 시트(`BottomSheet`)가 올라온다. 시트 안의 패널은 카드 모양 없이 공통 문법을 쓴다: 제목, 안내(`.hint`), 표(`.lines`·`.line`), 버튼 줄(`.acts`·`.go`), 고르기(`.picks`·`.pick`), 전체 폭 버튼(`.wide`).

시트는 상태·라운드·단계·전쟁·투표 마감이 바뀌면 닫힌다. 거래 시트는 거래가 끝나도 닫힌다. 다른 알림이 와도 닫히지 않는다. 시트가 재화 영역을 가릴 수 있어 거래 시트에는 오가는 재화의 보유량을 함께 보여 준다.

## 3. 알림

- `NoticeHost` 가 한 번에 하나씩, 확인을 누를 때까지 화면을 덮는다. 화면 테두리와 카드 테두리는 레인보우로 반짝이고 확인 버튼은 팀 색이다.
- 전쟁 선포는 전체 화면(사자 문장, 궁서체)이고 다른 알림보다 먼저 보여 준다.
- 거래 알림은 제목 → 방향(`화이트 → 레드`) → 설명 순서다. 수량은 오프라인에서 조정하므로 넣지 않는다.
- 다음 단계가 시작되면 쌓여 있던 진행 안내(단계 전환·모든 팀 완료·시간 종료)는 팝업에서 빼고 알림함에만 남긴다. 전쟁 뒤 자동 전환은 전쟁 결과 알림이 말해 주므로 처음부터 팝업하지 않는다.
- 시작 인트로와 테러리스트 카드가 떠 있는 동안에는 알림을 보여 주지 않고, 닫힌 뒤에 보여 준다.
- 관리자·프레젠테이션은 기존 `ToastHost` 를 그대로 쓴다.

## 4. 알림함

`InboxPanel`. 받은 알림 전체를 최신순으로 보여 준다. 읽은 위치(`inboxSeenId`)는 기기에 저장한다.

- 안 읽은 알림이 있으면 헤더의 종 아이콘 테두리만 깜빡이고 개수를 표시한다.
- 알림을 확인하면 그 알림까지, 알림함을 열면 전부 읽음이 된다.
- 연 시점에 안 읽었던 알림은 레인보우 테두리로 표시한다.

## 5. 폰트

- 제목·단계·이름: Black Han Sans (`--font-play`).
- 전쟁 선포: 궁서체 계열 (`--font-gungseo`). 기기에 없으면 Google Fonts 의 Song Myung 으로 보인다.
- 숫자: Archivo.
