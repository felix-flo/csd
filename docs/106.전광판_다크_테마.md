# 106. 전광판 다크 테마 (ApexDrill 톤)

2026-11-01. 관리자·프레젠테이션·참가자 세 화면을 모두 "스타디움 전광판" 톤으로 바꿨다. 레퍼런스는 Kombai 갤러리의 ApexDrill 대시보드
(https://kombai.com/gallery/inspirations/apexdrill/). 배치(docs/105)와 가시성 기준(docs/104)은 그대로 두고 색·폰트·선·모서리만 바꿨다.

## 1. 톤

| 항목 | 값 | 비고 |
|---|---|---|
| 캔버스 `--bg` | `#15171c` | 32px 격자 질감 (흰색 3.5%) |
| 패널 `--surface` | `#101216` | 카드·모달·토스트 |
| 우물 `--bg-soft` | `#1c1f26` | 입력·칩·표 머리글·미터 트랙·팀 카드 |
| 선 `--line-soft` / `--line` / `--line-strong` | `#2a2e37` / `#343946` / `#4b5262` | 카드 2px, 입력·칩 2px, 표 행 1px |
| 글자 `--ink` / `--muted` | `#f4f6fa` / `#a3abb8` | muted 는 캔버스 위 7.2:1 (레퍼런스의 45% 불투명도보다 밝게 — 빔·햇빛 고려) |
| 포인트 `--blue` | `#2d7cff` | 주요 버튼·켜진 칩·현재 단계·포커스·타이머 |
| 글로우 `--glow` | `rgba(45,124,255,.35)` | 큰 숫자 text-shadow |
| 완료 `--green` | `#27d17c` | 협의 결과·완료 배너 |
| 위험 `--red` | `#ff4d4d` | 오류·끊김·전쟁·타이머 경고 |
| 주의 `--amber` | `#ffb020` | 주의 뱃지·테스트 모드 |
| 모서리 `--radius` | `0` | 전부 각진 모서리 (팀 색 점만 원) |

그림자 없음. 깊이는 면 색 단계(캔버스 < 패널 < 우물)와 글로우로만 낸다.

## 2. 폰트

| 용도 | 폰트 | 비고 |
|---|---|---|
| 제목·큰 숫자 | **Archivo** 900, 자폭 125% (라틴·숫자) + **Black Han Sans** (한글) | 라틴은 대문자 + 자간 0.02~0.03em. 한글은 폴백으로 자동 |
| 라벨·칩·시각·수량 | **JetBrains Mono** 400~700 | tabular 숫자. `.label` 은 대문자 + 자간 0.14em |
| 본문 | **Manrope** 400~700 (라틴) + 시스템 한글 | |

모두 Google Fonts (`client/index.html`). Cafe24 PRO Slim 은 더 이상 쓰지 않아 `@font-face`·preload 를 지웠다 (`client/public/fonts/` 파일은 남겨 둠).

## 3. 컴포넌트

- **버튼**: 주요 = 파랑 채움, 대문자 700, 호버 시 흰 바탕 + 검정 글자. 보조 = 투명 + 2px 회색 선, 호버 시 파랑 선·글자. 위험 = 빨강.
- **입력**: 우물 바탕 + 2px 선, 포커스 파랑 + 글로우.
- **뱃지/칩**: 투명 + 2px 선, 모노 대문자. `on` 은 파랑 채움 흰 글자, `off` 빨강, `warn` 호박.
- **상단바**: 아래 2px 파란 줄. **단계 바**: 2px 선 + 왼쪽 4px 파랑, 현재 단계 칩 파랑 채움.
- **재화 칩**: 우물 바탕 + 2px 선, 숫자 색만 재화별 (보석 흰색·골드 `#ffc53d`·라이프 `#5b9cff`·크레딧 `#ff6b6b`). 💎 는 흑백 + 밝기 1.9.
- **카드 브래킷** `.bracket`: 22px ㄱ자 파란 모서리 2개. 프레젠테이션 타이머·안건 카드에 붙임.
- **프레젠테이션**: 타이머 숫자는 디스플레이 폰트 + 파란 글로우(경고·종료는 빨강), 협의 결과는 초록, 팀 카드는 우물 바탕 + 팀 색 띠 6px, 대기 화면 팀 글자(A/B/C/D)는 파랑 글로우. 골드 누적 숫자는 디스플레이 폰트 금색.
- **토스트·모달**: 패널 바탕 + 2px 선, 그림자 없음. 모달 배경은 검정 65%.
- **탈락 통보 오버레이**: 검정 90% + 빨강 제목 (이전엔 `--ink` 기반이라 다크에서 흰 화면이 됐을 것).
- **QR**: 스캔을 위해 흰 박스 유지.
- **팀 색 강조 `teamInk()`**: 밝은 색을 어둡게 바꾸던 규칙을 뒤집어, 아주 어두운 색(명도 0.2 미만)만 밝은 회색으로 바꾼다.

## 4. 아이콘 (이모지 대체)

UI 의 이모지를 모두 직접 그린 인라인 SVG 아이콘(`client/src/components/Icon.vue`)으로 바꿨다. 이모지는 기기마다 모양·색이 다르고(💎 는 하늘색, 🪙 는 Apple 에서 은색)
다크 바탕·빔에서 흐릿했다. 아이콘은 24×24 뷰박스, 2px 선, `currentColor` 라 글자 색·크기를 그대로 따른다.

| 이름 | 쓰임 | | 이름 | 쓰임 |
|---|---|---|---|---|
| `gem` `gold` `life` `credit` | 재화 칩·표 머리글·입력 라벨 (색은 `--res-*-fg`) | | `timer` | 단계 타이머 |
| `council` | 리더 협의 | | `aid` | 대가 없는 원조 |
| `war` | 전쟁 | | `scroll` | 라이프 투표권 안건 |
| `vote` | 최종 투표 | | `migration` | 이주 |
| `lock` | 마지막 라운드 발행 제한 | | `bell` `bell-off` | 알림음 켜짐/꺼짐 (상단바) |
| `mute` | 인트로 무음 | | `spy` | 테러리스트 |
| `sun` `moon` | 운명의 카드 | | `flask` | 테스트 모드 |
| `warning` | 주의 | | `refresh` | 새 버전 배너 |
| `megaphone` | 토스트·문서 갱신 배너 | | `film` | 오프닝 영상 |

- 사용: `<Icon name="war" />`. 클래스는 `icon icon-<name>` (부모 scoped 스타일의 `.timer` `.council` 같은 이름과 겹치지 않게 접두어).
- `lib/resources.ts` 의 `emoji` 필드는 삭제. 재화 칩(ResourceChip)은 `<Icon :name="kind" class="res-icon" />`.
- 서버 알림 메시지(`server/src/routes/game.ts`, `phaseTimer.ts`)와 `shared/game.ts` 의 라벨(`PHASE_TIMEOUT_MESSAGES`, `FATE_LABELS`)에서도 이모지를 뺐다. 토스트는 라벨 앞에 메가폰 아이콘만 붙는다.
- 룰북 마크다운(`docs/rules`, 관리자 룰 편집 내용)의 이모지는 콘텐츠라 그대로 둔다.
- 남은 글자 기호: 토스트 닫기 `✕`, 화살표 `→`, 가운뎃점 `·` (이모지가 아니라 문자).

## 5. 유지한 것

- 배치·크기(docs/104·105): 프레젠테이션 루트 20px, 보조 글자 0.78rem 하한, 1080p/720p 스크롤 없음. 다크에서는 회색·선을 한 단계 더 밝게 (`html[data-screen='present']`).
- 토스트 정책(docs/103 §6): 참가자만 마지막 알림 유지.
- 운명의 카드(FatePick)·대기 문구(ReadyLobby `.tale`)·인트로는 원래 어두운 톤이라 그대로.

## 6. 확인

- `npm run typecheck`, `npm run build -w client` 통과.
- 브라우저: 프레젠테이션(1343×896, 리더 협의 중) · 참가자(390px, 리더) · 관리자(게임 진행·팀 재화·룰 편집) 스크린샷으로 확인. 세 화면 모두 하드코딩된 밝은 색 잔재 없음, 아이콘 치환 뒤 남은 이모지 없음 (`grep` 으로 확인).
- 서버 `tsc --noEmit` 통과 (메시지 문자열만 바뀜).
- 남은 하드코딩 색: 인트로 레터박스(`#15171c`, 캔버스와 동일), QR 흰 박스, 운명의 카드 금색, 대기 문구 남색 — 모두 의도한 것.

## 7. 운영 메모

- 강당 조명을 켜고 진행하면 다크 화면은 빔 밝기에 따라 대비가 떨어질 수 있다. 리허설 때 뒷자리에서 타이머·팀 이름이 읽히는지 확인하고, 안 되면 `--bg` 를 `#0a0b0e` 로 더 어둡게 하거나 빔 밝기를 올린다.
- 밝은 테마로 되돌리려면 `git checkout main -- client/src/style.css client/index.html` 과 docs/106 §3 의 컴포넌트 변경을 되돌리면 된다 (브랜치 `design2` 에만 적용).
