# 108. 앱인토스 테마 (TDS Mobile · consumer UX guide)

2026-11-01, 브랜치 `design4`. 관리자·프레젠테이션·참가자 세 화면을 앱인토스 디자인 가이드(TDS Mobile)와 consumer UX guide 에 맞춰 바꿨다.
참고: https://developers-apps-in-toss.toss.im/design/components · https://developers-apps-in-toss.toss.im/landing-page/landing-page-en/design/consumer-ux-guide ·
TDS 문서 https://tossmini-docs.toss.im/tds-mobile/ (Colors, Typography, Button, Top, ListHeader, Badge, Toast, Tab, BottomCTA).
TDS Figma 키트·컴포넌트 코드는 라이선스상 앱인토스 전용이라 쓰지 않았고, 문서의 값·패턴만 따랐다.

## 2. 화면별

- **참가자**: 상단(팀 이름 22px + 보조) → 단계 탭 카드 → 지금 할 일(제목 22px) → 팀 재화 → 단계 패널 → 팀원 → 알림. 라이프 제출·최종 투표는 하단 고정 CTA. 선택 타일(최종 투표·이주)은 회색 면, 선택 시 연한 파랑.
- **프레젠테이션**: 배치(docs/105)는 그대로. 흰 카드(반경 16px) + 회색 바탕, 타이머 숫자 파랑 800, 팀 카드는 회색 면 + 팀 색 띠 5px, 완료 배너 연한 초록. 단계 탭은 카드 안 밑줄 탭.
- **관리자**: 흰 카드 + 회색 바탕, 표 머리글 13px grey600, 입력은 회색 면(포커스 파랑). 팝업 버튼 "닫기 / 확인".

## 3. 해요체 변환

`client/src`, `server/src`, `shared` 의 문자열에서 아래 어미를 규칙으로 바꿨다 (357곳 + 과거형 58곳).

- `~있습니다/없습니다/합니다/됩니다` → `~있어요/없어요/해요/돼요`, `~았/었/였/겠습니다` → `~았/었/였/겠어요`, `~ㅆ습니다` → `~ㅆ어요`
- `~입니다` → 받침 있으면 `~이에요`, 없으면 `~예요` (`보입니다→보여요`, `아닙니다→아니에요` 등은 따로 처리)
- `~하겠습니까?` → `~할까요?`, `~습니까?` → `~나요?`
- 동사 어간 규칙(`갑니다→가요`, `누릅니다→눌러요`, `만듭니다→만들어요` …)은 목록으로 처리. 남은 격식체는 없음 (`grep` 확인).
- 룰북 마크다운(`docs/rules`)과 docs/ 는 바꾸지 않았다.

## 4. 아이콘

`client/src/components/Icon.vue` 인라인 SVG 25종 (design2 에서 가져옴 + `close` 추가). 클래스 `icon icon-<name>`. 재화 아이콘 색은 `--res-*-fg`.
이모지는 UI·서버 메시지·공용 라벨에서 모두 뺐고(`lib/resources.ts` 의 `emoji` 삭제), 룰북 마크다운만 그대로.

## 5. 확인

- `npm run typecheck`, `npm run build -w client`, 서버 `tsc --noEmit` 통과.
- 브라우저: 프레젠테이션(1343×896, 리더 협의 중) · 참가자(390px, 리더 협의·라이프 제출 + 하단 CTA + 토스트 + 확인 팝업) · 관리자(게임 진행·팀 재화·룰 편집).

## 6. 메모

- 보조 글자는 grey600(`#6b7684`)으로 잡았다. TDS 의 grey500 은 흰 면 위 4.5:1 이 안 돼 docs/104 기준에 어긋난다.
- 프레젠테이션은 밝은 테마라 조명을 켠 강당에서 유리하다 (다크 테마 브랜치 design2·design3 와 반대).
- 브랜치 정리: `main` Geist, `design2` ApexDrill 전광판, `design3` CCFE 리그 대시보드, `design4` 앱인토스.
