# 104. 가시성 기준 — 프레젠테이션(빔)·참가자(휴대폰) 화면

> 작성일: 2026-10-30
> 상태: **구현 완료 (2026-10-30)**. 브라우저 확인은 본문 §검증
> 관련: [103.운영테스트_2차_수정.md](103.운영테스트_2차_수정.md) §6 §7 §14

운영 테스트에서 "프레젠테이션과 참가자 화면이 잘 안 보인다"는 지적이 나와 기준을 정하고 한 번에 손봤다.
두 화면은 보는 조건이 다르다. 프레젠테이션은 **빔으로 멀리서** 보고, 참가자는 **손에 든 휴대폰**으로 본다.

## 1. 참고한 가이드

| 대상 | 가이드 | 가져온 기준 |
|---|---|---|
| 공통 | WCAG 2.2 (W3C 웹 접근성 지침), KWCAG 2.2 (국내 표준) | 본문 대비 4.5:1 (1.4.3), 큰 글자(24px 이상) 3:1, 아이콘·테두리 3:1 근접 (1.4.11), 색만으로 정보 전달 금지 (1.4.1), 터치 대상 24px 이상 (2.5.8) |
| 프레젠테이션 | Google "Design for TV", Apple tvOS HIG, 발표 슬라이드 관행 | 시청 거리 기준 최소 글자 크기 (글자 높이 ≥ 거리 ÷ 200), 얇은 선·연한 회색 금지, 여백 확대 |
| 참가자 | Apple HIG Typography, Material 3 Type scale, NN/g Mobile Typography / Notifications | 본문 16~17px, 보조 글자 최소 11pt(≈ 14px)·절대 하한 12.5px, 핵심 정보 우선·진단용 메타 숨김 |
| 토스트·타이머 | Material 3 Snackbar, NN/g Indicators & Notifications | 한 번에 적게, 본문이 가장 크게, 남은 시간은 진행 막대로 |

빔 기준 계산: 1080p 를 높이 2.5m 로 투사하고 6m 뒤에서 본다고 하면 글자 높이 3cm ≈ 26px. 그래서 프레젠테이션의 읽을 글자는 **최소 1.3rem(26px)**, 핵심 숫자는 **2rem(40px) 이상**으로 잡았다.

## 2. 바꾼 것

### 전역 토큰 (`client/src/style.css`)

| 토큰 | 전 | 후 | 이유 |
|---|---|---|---|
| `--muted` | `#666` (5.7:1) | `#595959` (6.6:1) | 보조 글자 여유 확보 |
| `--line-soft` / `--line` / `--line-strong` | `#ebebeb` / `#e0e0e0` / `#b5b5b5` | `#e2e2e2` / `#c9c9c9` / `#8f8f8f` | 헤어라인이 빔·햇빛에서 사라지지 않게 |
| 보조 글자 최소 크기 (`.label`, `.badge`, `h2 .muted`, `.feed .muted`, 단계 칩) | 0.7~0.72rem (11~11.5px) | **0.78rem (12.5px)** | iOS 최소 11pt 이상 |
| 상단바 이름 | 0.75rem | 0.82rem | |

### 프레젠테이션 전용 스케일 (`html[data-screen='present']`)

`PresentView` 가 떠 있는 동안 `<html data-screen="present">` 를 켠다 (나가면 끔). 이 상태에서는

- **루트 글자 크기 20px** → rem 으로 적은 모든 크기가 1.25배. 본문 16px → 20px, 제목·칩·토스트도 같이 커진다.
- `--muted` `#444`, 선 `#d2d2d2 / #b4b4b4 / #7a7a7a` 로 더 진하게.
- 카드 안 보조 문구(`.note`) 1.1rem = 22px.

| 요소 | 전 (px) | 후 (px) |
|---|---|---|
| 단계 표시줄 "○○ 중" | 32 | 44 |
| 타이머 숫자 | 51 | 72 (tabular-nums, 진행 막대 6px) |
| 리더 협의 안건 | 22 / 보조 16 | 30 / 보조 22 |
| 팀 현황 팀 이름 / 팀원 | 26 / 18 | 36 / 26 (탈락자는 흐리게 대신 회색+취소선) |
| 현황판 골드 숫자 / 전쟁 줄 | 32 / 18 (전쟁 중 22) | 44 / 26 (전쟁 중 32) |
| 입장 현황 글자 A~D | 54 | 80 |
| 토스트 본문 (프레젠테이션) | 29 | 44 (전쟁 52), 폭 760px |
| 알림 피드 본문 | 16 | 20 |
| 페이지 폭 | 1100 | 1280 |

### 참가자 화면

- 알림 피드(`EventFeed plain`): `#id · type · 날짜시각` 진단용 메타와 "(마지막 id: N)" 를 숨기고 **시각(HH:MM, 기기 시간대)** 만. 관리자 화면은 그대로.
- 리더 협의 안내 문구를 회색 보조 글자에서 본문 색으로.
- 팀원 목록의 "(id N)" 제거.
- 프레젠테이션 알림 피드도 `plain`.

## 3. 안 바꾼 것 / 다음 후보

- 제목 폰트 Cafe24 PRO Slim 은 좁은 서체라 빔에서 획이 붙는다. 지금은 제목에만 쓰므로 두었다. 숫자·본문은 시스템 한글 폰트.
- 어두운 강의실이면 프레젠테이션을 다크 테마로 바꾸는 편이 더 잘 보인다. 필요하면 `html[data-screen='present']` 에 색 토큰만 덮어쓰면 된다.
- 토스트는 오른쪽 위에 쌓여 타이머 카드 일부를 덮을 수 있다 (1920px 기준 오른쪽 40%). 타이머는 왼쪽에 있어 숫자는 가려지지 않는다.

## 4. 검증 (2026-10-30)
