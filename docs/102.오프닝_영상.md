# 102. 오프닝 영상 — 게임 시작 때 프레젠테이션에서 mp4 재생

> 작성일: 2026-10-30
> 상태: **구현 완료 (2026-10-30)**. 영상 파일은 운영진이 직접 올린다 (§2)
> 관련: [95.게임진행_설계.md](95.게임진행_설계.md) (프레젠테이션), [101.테스트모드_탭로그인.md](101.테스트모드_탭로그인.md)

## 1. 동작

- 관리자가 **게임 시작**을 누르면, 열려 있던 프레젠테이션 화면이 **전체 화면(검정 배경)으로 영상을 튼다**. 영상이 끝나면(또는 건너뛰면) 지금처럼 게임 제목 리졸브 효과로 이어진다.
- 건너뛰기: 화면 **클릭** 또는 **ESC · Space · Enter**.
- 영상 파일이 없으면 아무 변화 없음 (제목 리졸브만).
- 시작 후 새로 열거나 새로고침한 프레젠테이션은 영상을 틀지 않는다 (제목 효과와 같은 기준).

## 2. 파일 두는 곳

| 환경 | 경로 | URL |
|---|---|---|
| Pi (컨테이너) | `data/media/intro.mp4` (= `/app/data/media/intro.mp4`, data 볼륨 안) | `/media/intro.mp4` |
| 로컬 `npm run dev` | `data/media/intro.mp4` (DB 옆) | 같음 (vite 가 `/media` 를 3000 으로 프록시) |

- 폴더·파일명 고정 (`intro.mp4`). 교체는 파일만 바꾸면 되고 재배포·재시작 불필요 (브라우저 캐시 1시간이라 바꾼 직후엔 프레젠테이션 새로고침).
- 다른 폴더를 쓰려면 `.env` 의 `MEDIA_DIR`.
- `data/` 는 git 에 안 들어가므로 영상은 Pi 에 직접 복사한다: `scp intro.mp4 pi:<serverconfig>/csd/data/media/`.
- 권장 인코딩: H.264 + AAC, 1080p. 브라우저(Chrome) 가 바로 재생하는 조합.

## 3. 소리 (브라우저 자동재생 정책)

- 탭에서 **한 번이라도 클릭·키 입력**이 있어야 소리 있는 재생이 허용된다. 그래서 준비 단계 프레젠테이션 화면에 "🎬 게임 시작 때 오프닝 영상을 틉니다. 소리를 내려면 이 화면을 한 번 클릭해 두세요 [영상 준비]" 안내를 띄우고, 클릭하면 "소리 재생 준비됨" 으로 바뀐다.
- 입력 없이 열어만 둔 탭이면 **소리 없이** 재생되고 우하단에 "🔇 소리 없이 재생 중 · 클릭하면 소리 켜기" 가 보인다. 그때 클릭하면 소리가 켜지고, 그다음 클릭이 건너뛰기다.

## 4. 구현

| 위치 | 내용 |
|---|---|
| `server/src/config.ts` | `mediaDir` (`MEDIA_DIR`, 기본 DB 옆 `media/`) |
| `server/src/index.ts` | `/media` 정적 서빙 (`express.static`, 폴더 없어도 서버는 뜸) |
| `server/src/routes/game.ts` | `GET /api/game/intro` (프레젠테이션·관리자) → `{ url: '/media/intro.mp4' \| null, size }` |
| `shared/game.ts` | `INTRO_FILE`, `IntroResponse` |
| `client/src/components/IntroVideo.vue` | 전체 화면 `<video>` 오버레이. 소리 재생 거부 시 음소거로 재시도, 끝/건너뛰기 → `done` |
| `client/src/views/PresentView.vue` | 시작 전환 감지 → 영상이 있으면 먼저 재생, `done` 뒤 제목 리졸브. 준비 화면 안내 문구 |
| `client/vite.config.ts` | `/media` 프록시 |

- 관리자 업로드 UI는 두지 않았다 (파일 복사로 충분). 필요하면 추가.
