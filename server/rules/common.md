## 🎯 이기는 방법
- 상금 화폐는 💎 보석 또는 🥇 골드. 무엇이 될지는 마지막 🗳️ 투표로
- 채택 화폐를 많이 가진 팀이 많이 가져감
- 💎 채택 → 옐로우 팀 보상 0, 🥇 채택 → 화이트 팀 보상 0
- 끝까지 살아남은 사람만 보상

> 모두가 나눠 갖는 게임이 아닙니다. 보상 0인 팀도 나옵니다.

## 👥 팀
| 팀 | 특징 |
|---|---|
| ⚪ 화이트 | 💎 보석을 발행 |
| 🟡 옐로우 | 🥇 골드를 발행 |
| 🔵 블루 | 💙 라이프가 가장 많고, 가장 많이 만듦 |
| 🔴 레드 | 🎟️ 크레딧을 가장 많이 만듦 |
| ⚫ 블랙 | 운영진 |

- 승패와 보상은 팀 단위
- 재화는 팀이 함께 가짐. 다른 팀 재화는 볼 수 없음
- 공간 제한 없음

## 💰 재화
| 재화 | 쓰임 |
|---|---|
| 💙 라이프 | 라운드 끝마다 1인당 1개 제출 |
| 🎟️ 크레딧 | 생산게임 참가 · 거래 수수료 · 전쟁 선포 |
| 💎 보석 | 보석 채택 시 보상 |
| 🥇 골드 | 골드 채택 시 보상 |

- 시작 시 전체: 💎 200 · 🥇 200 · 💙 39 · 🎟️ 24
- 팀별 보유량은 비공개
- 💎 보석 · 🥇 골드는 발행팀이 게임 중 더 발행함. 🥇 골드 발행량은 현황판에 공개, 💎 보석 발행량은 비공개

## 📅 오늘의 진행
1라운드 → 2라운드 → 3라운드 → 4라운드 (🧳 이주 시작) → 5라운드 → 6라운드 (마지막) → 🏁 최종장

> 4라운드 · 6라운드 · 최종장에는 새 규칙이 열립니다.

## 🔁 한 라운드의 순서
① 👑 리더 선출 → ② 🎮 생산게임 → ③ 🤝 거래 (⚔️ 전쟁 선포 가능) → ④ 🗣️ 리더 협의 → ⑤ 💙 라이프 제출

## ① 👑 리더 선출
- 매 라운드 팀마다 리더 1명. 앱에서 팀원 투표 (동표면 현 리더 유지). 팀원이 1명이면 투표 없이 리더
- 리더만: 거래 체결 · 전쟁 선포 · 리더 협의 · 라이프 제출
- 리더는 🧳 이주 신청 불가

## ② 🎮 생산게임
- 팀마다 🎟️ 1개 내고 참가. 없으면 참가 불가
- 시작 전 💙 라이프 / 🎟️ 크레딧 중 하나 선택
- 운영진과 미니게임 10판. 🎟️ 1개당 추가 1판 (최대 3판)
- 출전자는 팀이 정함

> 보상량은 아래 팀 룰에

## ③ 🤝 거래
- 리더가 앱에 올림 → 상대 리더가 수락하면 성립
- 수수료 🎟️ 1개. 누가 낼지는 두 팀이 정함
- 어떤 재화든 어떤 비율로든

## ⚔️ 전쟁
- 거래 시간에 리더가 🎟️ 내고 선포 → 진행자가 승인하면 시작. 비용은 매 라운드 공지
- 라운드당 1번. 취소 불가
- 거부하면 패배. 동맹 가능
- 🎮 스위치 마리오로 승부. 전쟁 중 거래 정지
- 이긴 팀이 진 팀 모든 재화의 절반 (내림)
- 오간 재화는 두 팀만 확인. 다른 팀에는 승패만

## ④ 🗣️ 리더 협의
- 리더 4명 중 3명 찬성으로 통과
- 원조: 주는 팀 리더가 먼저 선언. 통과 시 수수료 없이 재화 양도 (주는 팀은 라운드당 1번)
- 운영진 안건: 예) 다음 라운드 전쟁 금지

## ⑤ 💙 라이프 제출
- 리더가 **살릴 인원 수**를 입력. 쓴 만큼만 생존
- 리더는 생존, 나머지는 무작위. 자진 탈락은 리더만
- 라이프 0개여도 1명은 생존
- 탈락하면 보상 없음. 팀 재화는 팀에 남음

> 예) 5명 팀, 3개 사용 → 리더 + 4명 중 무작위 2명 생존

## 🧳 이주 (4라운드부터)
- 6라운드까지. 라이프 제출 단계만 빼고 언제든
- 앱으로 신청 → 받는 팀 리더에게만 전달 → 수락 시 전체 공지, 즉시 소속 변경
- 빈손으로 이동. 이후 라이프는 새 팀이 냄
- 리더는 신청 불가. 한 사람당 1번만

## 6️⃣ 6라운드 (마지막)
- 발행팀의 마지막 발행이 있음. 이번 발행량은 최종장 결과 때 공개
- 리더 협의 필수 안건: **남은 라이프를 최종 투표권으로 인정할까요?** 통과 시 💙 1개 = 🗳️ 1표 (1인 1장). 부결이면 리더만 투표
- 최종장에는 거래 · 발행 · 원조 · 이주 없음

## 🏁 최종장
① 🗳️ 최종 투표 → ② 결과 발표 → ③ 🏆 보상

## 🗳️ 최종 투표
- 앱에서 비밀 · 동시. 기본 1표는 **리더만**
- (안건 통과 시) 💙 1개로 1표, 1인 1장. 리더는 1표 더, 팀원은 이것으로 투표
- 화폐로 표를 살 수 없음. 한 번 내면 수정 불가. 안 내면 기권
- 동점이면 화이트 · 옐로우 리더 가위바위보

## 🏆 보상
- 우리 팀 보상 = 전체 × (우리 팀 채택 화폐 ÷ 모든 팀 채택 화폐)
- 채택되지 않은 화폐 · 라이프 · 크레딧은 0

> 예) 💎 채택, 전체 1,000개 중 우리 300개 → 30%
